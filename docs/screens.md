# خريطة شاشات TeleCore — إنتاجي

كل شاشة مربوطة بـ API حقيقي: حفظ إعدادات، تشغيل عمليات، قوائم، تأكيدات خطرة، واستئناف.

|---|---|
| مصادقة | `/login` |
| الرئيسية | `/` |
| الحسابات | `/accounts` + إضافة OTP/QR + قائمة + تفاصيل + فحص + تسخين + مجموعات + ملف شخصي + تصدير + غير النشطة |
| التجميع | 7 خطوات للقروب العام + دعوة + رسائل + تفاعلات + جماعي + اكتشاف + تنقية + دمج + ملفات + قوالب + استئناف |
| الإضافة | 8 خطوات من ملف + يدوي بتحقق + ذكي + متعدد + دعوة + سوداء + استئناف |
| التدوير | لوحة + إعدادات + جدول + ترتيب + استهلاك + تصفير + ذكي + دوام + سيناريوهات + مراقب + قواعد |
| البروكسي | إضافة + استيراد + قائمة + تفاصيل + فحص + تعيين + استبدال ميت + تنظيف + إحصاء + تصدير |

| DM / القروبات | إنشاء + قائمة + تشغيل/إيقاف + قوالب + جدولة + دليل + إحصاء |
