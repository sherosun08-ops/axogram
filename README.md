# TeleCore

منصة ويب SaaS كاملة (واجهة + خادم) لإدارة حسابات تيليجرام، التجميع، الإضافة، التدوير، البروكسي، الأمان، التقارير، الرسائل الجماعية، وحملات القروبات.

التصميم مبني على ملفات المواصفات في جذر المستودع (`0.0general` حتى `10حملات القروبات`).

## التشغيل

```bash
cd web
npm install
npm run dev
```

يفتح على `http://localhost:3000`

### حساب التجربة

- البريد: `admin@telecore.app`
- كلمة المرور: `TeleCore@2026`

## البنية

```
web/
  src/app/(app)/          كل شاشات المنتج منظّمة حسب القسم
    accounts/             مدير الحسابات
    gather/               تجميع الأعضاء
    adder/                إضافة الأعضاء
    rotation/             نظام التدوير
    proxy/                مدير البروكسي
    settings/             الإعدادات
    reports/              التقارير والسجلات
    security/             أدوات الأمان
    messages/             الرسائل الجماعية
    campaigns/            حملات القروبات
  src/app/api/            واجهات REST للخادم
  src/components/         نظام التصميم والمكوّنات
  src/lib/                المصادقة، المخزن، التسميات
  data/                   قاعدة البيانات JSON (تُنشأ تلقائياً)
```

## الأقسام والشاشات

أكثر من 120 شاشة مطابقة لقائمة التصميم: لوحات، تدفقات OTP/QR، استيراد جلسات، فحص صحة، تسخين، مجموعات، ملفات تجميع، عمليات حيّة، قفل طوارئ، وغيرها.

الخادم يوفّر REST لكل الكيانات مع محرّك عمليات يحاكي التقدّم الحي (تجميع / إضافة / فحص / تسخين).
